\# Backgammon



A standalone desktop version of Backgammon developed by Alexandre Careme.



\## Windows Version



The Windows version is provided as a `.msi` installer.



\### Installation



1\. Open `Backgammon-1.0.msi`.

2\. Follow the installation instructions.

3\. After installation, open \*\*Backgammon\*\* from the Start Menu or from the installed application.

4\. To uninstall, use \*\*Installed apps\*\* in Windows Settings.



The packaged application includes its own Java runtime and JavaFX libraries, so \*\*Java, JavaFX, Maven, and IntelliJ IDEA are not required\*\* to run the game.



The Windows release is packaged for \*\*64-bit Windows\*\*.



\## macOS Version



The macOS version is provided as a `.dmg` installer.



\### Installation



1\. Open `Backgammon-1.0.dmg`.

2\. Drag \*\*Backgammon\*\* into the \*\*Applications\*\* folder.

3\. Eject the DMG.

4\. Open \*\*Backgammon\*\* from Applications.



The packaged application includes its own Java runtime and JavaFX libraries, so \*\*Java, JavaFX, Maven, and IntelliJ IDEA are not required\*\* to run the game.



The macOS release is packaged for \*\*Apple Silicon (aarch64)\*\* Macs.
